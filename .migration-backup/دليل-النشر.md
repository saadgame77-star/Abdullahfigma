تم إنشاء جميع الملفات المطلوبة:
- ✅ `index.html` - صفحة HTML الرئيسية

## 📋 الطريقة الأولى: النشر على **Vercel** (الأسهل والأسرع) ⭐

### الخطوة 1: تحميل المشروع
1. اضغط زر تحميل على جميع ملفات المشروع
2. أو اضغطها في ملف ZIP

### الخطوة 2: إنشاء حساب GitHub (إذا لم يكن لديك)
1. اذهب إلى: https://github.com
2. اضغط "Sign up"
3. أكمل التسجيل

### الخطوة 3: رفع المشروع إلى GitHub
#### الطريقة الأولى (من خلال موقع GitHub):
1. اذهب إلى: https://github.com/new
2. اسم المشروع: `sheikh-website` (أو أي اسم تريده)
3. اجعله `Public` أو `Private` حسب رغبتك
4. اضغط "Create repository"
5. اضغط "uploading an existing file"
6. اسحب جميع الملفات أو اختر "choose your files"
7. اضغط "Commit changes"

#### الطريقة الثانية (من خلال سطر الأوامر):
```bash
git init
git add .
git commit -m "إضافة الموقع الكامل"
git branch -M main
git remote add origin https://github.com/your-username/sheikh-website.git
git push -u origin main
```

### الخطوة 4: النشر على Vercel
1. اذهب إلى: https://vercel.com
2. اضغط "Sign up" واختر "Continue with GitHub"
3. بعد تسجيل الدخول، اضغط "Add New..." ثم "Project"
4. اختر repository المشروع من القائمة
5. Vercel ستكتشف تلقائياً أنه مشروع Vite
6. تأكد من الإعدادات:
   - Framework Preset: `Vite`
   - Build Command: `pnpm build` (أو `npm run build`)
   - Output Directory: `dist`
   - Install Command: `pnpm install` (أو `npm install`)
7. اضغط "Deploy"
8. انتظر دقيقة واحدة... ✨

### 🎉 تم النشر!
سيكون لديك رابط مثل: `https://sheikh-website.vercel.app`

### إضافة نطاق خاص (اختياري):
1. في لوحة Vercel، اذهب إلى "Settings" → "Domains"
2. أضف نطاقك المخصص مثل: `sheikh-alghulayyis.com`
3. اتبع التعليمات لتوجيه DNS

## 📋 الطريقة الثانية: النشر على **Netlify**

### الخطوات:
1. ارفع المشروع إلى GitHub (نفس خطوات Vercel أعلاه)
2. اذهب إلى: https://netlify.com
3. اضغط "Sign up" واختر GitHub
4. اضغط "Add new site" → "Import an existing project"
5. اختر GitHub واختر repository المشروع
6. الإعدادات (ستظهر تلقائياً من ملف `netlify.toml`):
   - Build command: `pnpm build`
   - Publish directory: `dist`
7. اضغط "Deploy site"

### 🎉 تم النشر!
سيكون لديك رابط مثل: `https://sheikh-website.netlify.app`

---

## 📋 الطريقة الثالثة: النشر على **Replit**

### الخطوات:
1. اذهب إلى: https://replit.com
2. اضغط "Sign up" أو "Log in"
3. اضغط "+ Create Repl"
4. اختر "Import from GitHub" أو "Upload files"
5. إذا اخترت Upload:
   - اسحب جميع ملفات المشروع
   - أو ارفع ملف ZIP
6. Replit ستكتشف تلقائياً الإعدادات من ملف `.replit`
7. اضغط "Run" في الأعلى

### 🎉 سيعمل الموقع مباشرة!

## 🔧 حل المشاكل الشائعة

### المشكلة: "Module not found"
**الحل:**
```bash
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### المشكلة: صفحة بيضاء بعد النشر
**الحل:**
- تأكد من أن `index.html` في الجذر الرئيسي
- تأكد من أن `src/main.tsx` موجود
- تحقق من console في المتصفح للأخطاء

### المشكلة: الخطوط لا تظهر
**الحل:**
- تأكد من اتصال الإنترنت (الخطوط تُحمّل من Google Fonts)
- تحقق من ملف `src/styles/fonts.css`
