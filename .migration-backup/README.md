# موقع الشيخ عبدالله بن سعد آل غلفيص

موقع إلكتروني احترافي بطابع إسلامي علمي رصين لعرض الدروس العلمية والكلمات الدعوية.

## 🎨 المميزات

- تصميم إسلامي احترافي بألوان متناسقة (أخضر داكن، ذهبي، عاجي)
- دعم كامل للغة العربية واتجاه RTL
- متجاوب مع جميع الأجهزة (Desktop, Tablet, Mobile)
- منصة فيديو متكاملة
- 9 صفحات رئيسية تشمل:
  - الصفحة الرئيسية
  - الدروس العلمية
  - السلاسل العلمية
  - الكلمات الدعوية
  - المقاطع القصيرة
  - جدول المحاضرات والدروس
  - متفرقات
  - من أنا
  - تواصل معي

## 🚀 التقنيات المستخدمة

- **React 18** - مكتبة بناء واجهات المستخدم
- **TypeScript** - للكتابة الآمنة
- **Vite** - أداة البناء السريعة
- **Tailwind CSS v4** - للتنسيق
- **React Router** - للتنقل بين الصفحات
- **Material-UI** - مكتبة مكونات UI
- **Lucide React** - مكتبة الأيقونات

## 📦 التثبيت والتشغيل

### متطلبات النظام
- Node.js (v18 أو أحدث)
- pnpm (يفضل) أو npm

### خطوات التشغيل

1. **تثبيت المكتبات:**
```bash
pnpm install
# أو
npm install
```

2. **تشغيل المشروع محلياً:**
```bash
pnpm dev
# أو
npm run dev
```
المشروع سيعمل على: `http://localhost:5173`

3. **بناء المشروع للإنتاج:**
```bash
pnpm build
# أو
npm run build
```

4. **معاينة نسخة الإنتاج:**
```bash
pnpm preview
# أو
npm run preview
```

## 🌐 النشر على الإنترنت

### Vercel (موصى به)
1. ارفع المشروع على GitHub
2. اذهب إلى [vercel.com](https://vercel.com)
3. استورد المشروع من GitHub
4. Vercel ستكتشف الإعدادات تلقائياً

### Netlify
1. ارفع المشروع على GitHub
2. اذهب إلى [netlify.com](https://netlify.com)
3. استورد المشروع
4. استخدم الإعدادات:
   - Build command: `pnpm build`
   - Publish directory: `dist`

### Replit
1. أنشئ Repl جديد من نوع "React + Vite"
2. ارفع ملفات المشروع
3. سيعمل تلقائياً

```
├── src/
│   ├── app/

│   │   ├── routes.tsx       # إعدادات التوجيه

```
